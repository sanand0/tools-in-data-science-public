# Google Dorking: Search Smarter, Not Harder 🔍

 **Google Dorking** is the use of **advanced Google search operators** to find specific information more efficiently. It's often called **Google Hacking**, but by itself it is **not hacking**, it's simply using Google more effectively.

## Why Learn Google Dorking?

It helps you:

- Find lecture notes and books
- Search research papers
- Discover documentation
- Find PDFs, PPTs, and datasets
- Perform ethical security research



## Common Search Operators

| Operator | Purpose | Example |
|----------|---------|---------|
| `site:` | Search within a website | `site:iitm.ac.in statistics` |
| `filetype:` | Find specific file types | `filetype:pdf linear algebra` |
| `intitle:` | Search page titles | `intitle:"machine learning"` |
| `inurl:` | Search URLs | `inurl:blog python` |
| `" "` | Exact phrase | `"Support Vector Machine"` |
| `-` | Exclude a word | `python tutorial -django` |

Google officially supports operators like `site:` and `filetype:` to refine searches.


## Practical Examples

### Find PDF Notes

```text
filetype:pdf linear algebra
```

### Search Only IIT Madras Website

```text
site:iitm.ac.in machine learning
```

### Find Python Documentation

```text
site:docs.python.org decorators
```

### Search Research Papers

```text
site:arxiv.org reinforcement learning
```

### Search Stack Overflow Only

```text
site:stackoverflow.com pandas merge
```


## Combine Operators

The real power comes from combining operators.

```text
site:github.com filetype:md transformers tutorial
```

This searches for **Markdown files** on **GitHub** related to **Transformers tutorials**.
